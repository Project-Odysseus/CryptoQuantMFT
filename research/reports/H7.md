# H7: Halve the trend rules after a flat stretch — report

**Verdict: INCONCLUSIVE, all three pass criteria failed. The gate is not built.**
Reproduce: `python scripts/research/h7_study.py --no-ledger` (logged run `data/research/h7_20261004T081751Z/`, 1 trial).

## 1. Pre-registration and deviations

`research/prereg/H7.txt`, version 1 (d7dda52170e2), locked and committed before the test. The first run stopped on a
config error before producing any number (a risk group named coins the cut-down config no longer had); fixed and run
once. No other deviation.

## 2. Where the idea came from

`scripts/research/regime_study.py` on the multi-strategy book, 2022-10-10 to 2025-12-31. A day is "flat" when
Bitcoin's 60-day efficiency ratio is in the lowest third of its own previous year, known two days ahead.

| Strategy | Flat days | Middling | Trending |
| --- | --- | --- | --- |
| taker basket | +40% (Sharpe 2.1) | +38% | +14% |
| btc_ma_1d | -25% | +91% | +120% |
| btc_keltner_ls | -78% | +36% | +117% |
| eth_ma_1d | -76% | +115% | +72% |
| eth_keltner_ls | -43% | +21% | +59% |
| sol_ma_1d | -53% | +10% | +147% |
| whole book | -36% (Sharpe -1.8) | +52% | +75% |

(% a year.) By volatility the split is weaker: every strategy does best in the middle third.

## 3. The test: the same split on 2020-09-14 to 2022-10-09, not looked at before

| | Test sample | Window the idea came from |
| --- | --- | --- |
| Days (flat) | 756 (283) | 1,179 (390) |
| Trend book on flat days, a year | **+47%** | -55% |
| Trend book on other days | +106% | +80% |
| Difference (95% interval) | -59 (-187 to +52) | -135 (-207 to -73) |
| Sharpe ungated / gated | 1.90 / 1.75 | 0.92 / 1.18 |
| Worst drawdown ungated / gated | 21% / 21% | 39% / 31% |
| Size changes | 67 | 102 |

In the test sample the trend rules made money on flat days: +70% a year in 2020, +90% in 2021, -14% in 2022. Every
strategy was positive there. Halving them would have cost return and Sharpe and saved no drawdown.

## 4. What this means

- The pattern "trend rules lose after a flat stretch" held in 2022-2025 and not in 2020-2022. Flat days were still
  worse than other days in both, but in a bull market "worse" was still strongly positive.
- The label changes state about once every 11 days, so a gate would also trade often.
- No regime gate is built. The one thing that did hold in the first window, and was not what H7 tested, is that the
  taker basket earns in flat stretches while the trend rules don't: the case for keeping both in one book.
